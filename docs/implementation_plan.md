## 二、 核心规则与业务逻辑梳理

1. **牌型与大小判定**：
   * 采用标准 52 张扑克牌（无大小王）。
   * 牌型大小：**豹子 (AAA > ... > 222) > 同花顺 > 金花 > 顺子 > 对子 > 单张**。
   * 特殊规则：**不同花色 235 在场上有豹子时吃豹子**；无豹子时作为最小单牌。
   * 平局处理：**同牌型时主动发起比牌者判负**。
2. **对局节奏与下注规则**：
   * **底注**：开局所有在座准备玩家自动扣除底注进奖池。
   * **暗注与明注**：未看牌（闷牌）下注倍率为 1x；已看牌（明注）必须下注 2x。
   * **比牌条件**：第 2 轮起开放自由选择对手比牌，比牌需扣除当前注额的 2 倍。
   * **封顶限制**：单局上限 20 轮，达到 20 轮强制全员亮牌比大小结算，赢家独揽底池。
3. **独立经济系统**：
   * 零外部注册：管理员统一在后台开号分配给朋友。
   * 钱包筹码直通牌桌：下注直接扣除钱包余额，获胜实时返还入账，掉线重登筹码分毫不差。

## 三、 前端极致流畅度设计

1. **视觉与动效 (60 FPS+ 硬件加速)**：
   * **CSS 3D 翻牌手感**：利用 `perspective: 1000px` 与 `transform-style: preserve-3d`，看牌时光影翻转自然流畅。
   * **自适应椭圆牌桌**：采用三角函数 `cos/sin` 动态计算 2~8 人的环形座位排布，当前玩家始终居于正下方第一人称操作位。
   * **筹码抛投轨迹**：下注时筹码带弧线飞向桌面中央底池，结算时底池筹码流光飞向获胜者。
2. **全套沉浸式音效**：
   * 发牌刷刷声、推筹码清脆碰撞声、翻牌看牌声、紧张比牌音效、获胜金币欢呼声，均采用 Web Audio API / 轻量音频无损即时播放。
3. **移动端深度优化**：
   * 适配 iOS/Android 防橡皮筋回弹、支持全屏体验与刘海屏适配。

## 四、 实施路线图 (Milestones)

- [ ] **Phase 1: 项目底座搭建与 SQLite 经济系统**
  - 初始化统一工程目录（Express + React + Tailwind + Vite）。
  - 集成 SQLite 数据库驱动（`better-sqlite3`），设计用户表、账本流水表。
  - 实现管理员后台 API 与管理界面（开通账号、分配密码、直接增减筹码、查看玩家状态）。
  - 实现玩家登录鉴权（JWT / Session）与钱包余额接口。

- [ ] **Phase 2: 炸金花核心规则与裁判引擎**
  - 编写牌库生成、洗牌（Fisher-Yates 算法）、发牌逻辑。
  - 编写严密的牌型判别与比较算法（单张、对子、顺子、金花、同花顺、豹子、特殊 235 吃豹子、同点数主动方负）。
  - 编写完整的单元测试，覆盖所有极端比牌场景。

- [ ] **Phase 3: 房间状态机与 Socket.io 联机网关**
  - 房间管理：创建房间（支持自定义底注、倒计时秒数）、房间号进房、链接分享。
  - 桌位管理：2~8 人自适应入座、离开、准备状态、观战席位广播。
  - 对局流转：下底注、轮转出资、看牌广播（仅自身可见暗牌）、跟注、加注、弃牌、定向比牌动画广播。
  - 倒计时控制器：支持房主设定超时秒数，超时自动弃牌，断线保护与重连手牌恢复。

- [ ] **Phase 4: 高性能前端桌面 UI 与 3D 交互**
  - 打造深色奢华绿色毛呢牌桌，集成动态环形座位计算。
  - 实现 3D 拟真翻牌组件、抛筹码粒子动画、比牌专属碰撞动画。
  - 集成全套音效、静音开关、快捷短语与互动表情气泡浮窗。
  - 优化移动端手势与响应式布局。

- [ ] **Phase 5: 一体化打包与生产部署准备**
  - 配置生产环境单端口静态托管，支持 Docker / PM2 一键启动。
  - 局域网/公网联机测试与极限边界测试。
