# 炸金花游戏 —— 前端专属设计需求与交互开发规范

> **使用说明**：本文档专门用于指导**前端开发对话**。前端工程师可完全根据本文档，独立搭建 React + Vite + Tailwind CSS 项目，配合内置 Mock 机制，在无后端环境下先行把所有高保真界面、3D 翻牌手感、动态排座与对局动效 100% 跑通。
> 数据接口与 WebSocket 契约统一参照：`api_specification.md`。

---

## 一、 项目技术栈与工程定位
* **技术底座**：React 18 + Vite + Tailwind CSS + Lucide React 图标库。
* **开发策略**：**前端先行（Mock 驱动）**。内置可一键开关的 `MockGameStore`，可手动模拟发牌、看牌、加注、PK 对决、结算与特效。
* **端适配**：极致响应式，针对手机移动端优化（屏蔽双击放大、防下拉橡皮筋回弹、适配刘海屏 `safe-area-inset`），兼顾 PC 宽屏沉浸感。

## 三、 牌桌核心交互与视觉动效规范（重点）

### 3.1 动态 8 人自适应桌位算法 (第一人称视角)
* **核心原则**：当前操作玩家永远处于牌桌的正下方底部中央，其余玩家（1~7人）根据在座人数动态在椭圆牌桌上方及左右两侧均匀环形分布。
* **位置计算数学模型**：
  设在座最大有效人数为 $N$（2~8），当前玩家在全量桌位数组中的物理索引为 $myIndex$。
  对于任意座位 $i$：
  $$\theta = \frac{2\pi \times (i - myIndex)}{N} + \frac{\pi}{2}$$
  $$X = CenterX + RadiusX \times \cos(\theta)$$
  $$Y = CenterY + RadiusY \times \sin(\theta)$$
  *前端需做平滑缓动过渡，当有新人入座或离座时，桌位自动重排。*

### 3.2 3D 拟真翻牌手感 (GPU 硬件加速)
* **未看牌状态**：三张牌背朝上微微重叠错开呈扇形，附带暗色微光；
* **翻牌手感**：
  * 点击“看牌”按钮，卡牌以 3D 轴向（`transform: rotateY(180deg)`，透视度 `perspective: 1000px`）立体翻转展出正面；
  * 翻开瞬间伴随清脆的“卡牌轻擦声”，正面清晰标明花色（黑桃/红桃/梅花/方块）与点数；
  * 自身牌面右下角打上识别后的牌型标签（如：“豹子 AAA”、“金花 K最大”）。

### 3.3 下注操作面板与专属特效
* **快捷加注档位**：固定提供 `+10`、`+20`、`+50`、`+100`、`+1000` 与 `All-in` 快捷按钮。
* **加注视觉反馈**：
  * 普通加注：从玩家头像位置生成一枚或一组筹码实体，带抛物线弧度平滑飞入牌桌正中奖池（飞入耗时约 400ms），底池数字滚动增加；
  * **5000+ 高额加注专属特效**：当加注金额 $\ge 5000$ 时，触发金光离子环绕特效，并在屏幕上方显示金色流光横幅；
  * **All-in 专属震撼特效**：点击全押时，屏幕四周触发暗红雷电震颤动效，全场伴随沉重的心跳声与碎石砸击音效，气势拉满！

### 3.4 绝密比牌决斗 (PK 碰撞对决)
* **比牌流程**：
  1. 玩家点击“比牌”按钮，牌桌上所有其他存活对手头像亮起呼吸光圈，并在其正上方显示“PK 挑战”靶心图标；
  2. 点击目标对手，消耗当前单注 2 倍筹码；
  3. 屏幕正中央弹出双人 1v1 决斗特写镜头，两张暗色扑克牌带着烈焰与闪电在中线强烈撞击；
  4. 碰撞爆炸后，**绝不公开双方底牌**，仅在输家头像上打上暗灰色“战败”印戳，输家手牌变为灰暗盖牌并推入弃牌堆。

### 3.5 终局结算动效
* 当对局决出胜者时，桌面中央底池内的所有筹码化作多道金色光流，旋转汇入胜者头像位置；
* 播放金币哗啦啦落袋欢呼音效，弹出胜者战报卡片（展示获胜金额，若因全员弃牌获胜则可点击“亮牌炫耀”）。

## 四、 拟真音效系统设计 (Web Audio API)
为免去外部庞大 mp3 文件的加载与跨域问题，系统采用轻量高保真 Web Audio 振荡器与音频合成：
* `playDealCardSound()`: 发牌时短促白噪声轻擦音；
* `playFlipCardSound()`: 看牌时清脆的翻折声；
* `playChipSound()`: 筹码撞击清脆金属/陶瓷声；
* `playPKClashSound()`: 比牌决斗烈火对撞声；
* `playAllInSound()`: All-in 沉重低音与雷鸣声；
* `playWinSound()`: 终局结算金币滚落欢呼声；
* *全局右上角提供一键静音/开启声音图标按钮。*

## 五、 互动与社交体系
* **快捷表情浮空动画**：点击表情面板（🔥 烈火、😎 墨镜帅、😭 痛哭、💀 绝望骷髅、💰 金币眼），在玩家头像上方生成 2.5 秒浮动放大淡出气泡。
* **快捷短语**：点击如“快点吧，等得花儿都谢了！”、“梭哈是一种智慧”，在头像旁冒出漫画对话框。

## 六、 独立 Mock 开发模式指南

前端工程师在开发时，可建立 `src/mocks/mockState.ts`：
1. 界面左下角提供一个隐藏式 DevTool 开关：
   * `[发牌测试]`：一键给在座 4 名模拟玩家发牌；
   * `[看牌测试]`：翻开自己的手牌；
   * `[下注测试 +100 / +5000 / Allin]`：快速查看抛筹码和震撼特效；
   * `[比牌 PK 模拟]`：触发 1v1 对撞动画；
   * `[结算模拟]`：模拟金币回流赢家。
2. 确保在完全没有 Node.js 后端启动的情况下，即可在浏览器中丝滑演示全部视觉与操作。
